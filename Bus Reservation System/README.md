# 🚌 Bus Reservation System

A Python-based Bus Reservation System with a user-friendly graphical interface. The application allows users to search for buses, select seats, book tickets, view reservations, and cancel bookings.

## ✨ Features

- 🔍 Search available buses
- 🚌 View bus details
- 💺 Interactive seat selection
- 🎫 Book bus tickets
- 👤 Enter passenger details
- 💰 Automatic fare calculation
- 🧾 Generate booking ID
- 📋 View all reservations
- ❌ Cancel reservations
- 💾 SQLite database
- 🖥️ Clickable Tkinter GUI
- ⚡ Single Python script

## 🛠️ Technologies Used

- Python
- Tkinter
- SQLite
- Object-Oriented Programming
- SQL
